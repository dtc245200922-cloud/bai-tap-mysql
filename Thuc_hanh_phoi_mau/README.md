# Thực hành sử dụng màu sắc trong trang web

Mã nguồn dựa trên Pra.zip của CodeGym. Giữ bố cục, nội dung, hình ảnh và font chữ gốc.

## Chạy bài
Mở `index.html` để xem bản xanh. Mở `purple.html` để xem bản tím hoặc dùng liên kết chuyển màu đầu trang. Không cần cài thư viện.

## Bảng màu
| Vị trí | Bản xanh | Bản tím |
| --- | --- | --- |
| Màu chủ đạo, ON SALE/PREVIEW | #00ADEE | #7C3AED |
| Màu bậc 2, nút nhấn | #00B2EF | #8B5CF6 |
| Nền trang, banner | #00BFF2 | #A78BFA |
| Nội dung | #8DD7F7 | #DDD6FE |
| Footer | #C6E9FA | #EDE9FE |

Chữ toàn trang dùng màu đen. Bản tím dùng các sắc độ cùng tông để thực hành bước 8.
