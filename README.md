# Trang đọc truyện ngắn

Mở `index.html` bằng trình duyệt để xem bài. Trang sử dụng CSS ngoài, ảnh SVG cục bộ và ba truyện ngắn tự sáng tác.

Mục lục dùng thẻ h5 và liên kết tới id từng truyện. styles.css định dạng font, màu, tiêu đề căn giữa, khung mục lục, hover, canh lề, giãn dòng và thụt đầu dòng. Trang có bố cục cho điện thoại.

## Đưa lên GitHub

Tạo repository Public tên trang-doc-truyen-ngan. Chọn Add file → Upload files, tải tất cả file trong thư mục này lên rồi Commit changes. Sao chép URL repository để nộp.

Nếu muốn có link xem trang: Settings → Pages → Deploy from a branch → main → /(root) → Save. Dùng URL do GitHub hiển thị khi triển khai hoàn tất.
