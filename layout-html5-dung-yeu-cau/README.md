# Bài tập: Tạo layout với các thẻ HTML5 và CSS

## Chạy bài
Mở file index.html bằng trình duyệt. File styles.css phải nằm cùng thư mục.

## Các thành phần
- header: phần đầu trang.
- nav: thanh điều hướng.
- section: khu vực nội dung chính.
- article: hai bài viết độc lập.
- aside: thanh thông tin bổ sung bên phải.
- footer: phần chân trang.

CSS Grid chia nội dung thành hai cột và chuyển về một cột trên màn hình nhỏ.

## Nộp bài
Tạo repository GitHub riêng, ví dụ bai-tap-layout-html5.
Upload index.html, styles.css và README.md vào repository đó.
Nộp link repository vừa tạo. Nếu dùng repository chung, nộp link trực tiếp đến thư mục chứa bài này.
