# Tạo layout với RWD

Bài sử dụng DIV và CSS theo ảnh đề bài: menu Logo/Home/About/Projects/Contact/Login, cột Link bên trái, Welcome/Test ở giữa, hai ô ADS bên phải và Footer Text.

## Chạy
Mở index.html trong trình duyệt, giữ styles.css cùng thư mục.

## Responsive
- Trên 991px: ba cột, tỉ lệ 1:4:1.
- Từ 601px đến 991px: hai cột đầu giữ cạnh nhau, phần ADS xuống dưới.
- Từ 600px trở xuống: các cột xếp dọc và menu tự xuống hàng.

## Nộp
Upload index.html, styles.css và README.md lên repository GitHub riêng tên bai-tap-layout-rwd. Nộp link repository đó hoặc link đúng thư mục bài nếu dùng repository chung.
